**Здесь размещена диагностическая сборка без грузовых перевозок.** Это первый тест исходного Renault Master, а не готовый грузовой мод. Версия игры для проверки: **ETS2 1.61.1.1s**.

## Назначение сборки

Сохранены исходные модели, звуки, интерьер, аксессуары и настройки автомобиля. Грузы, оплачиваемые рейсы, переделка сидений и калибровка расхода ещё не добавлены. Технический скрытый прицеп не добавлен.

Автор предоставленного исходного мода — **Gaza**. Подготовлено для личного тестирования пользователя.

Целостность архива проверена. **Игровая совместимость пока не подтверждена:** ETS2 в облачной среде не запускалась. Следующий шаг — проверить автомобиль в установленной игре и получить `game.log.txt` этого запуска.

## Короткая инструкция

1. Используйте отдельный тестовый профиль или копию сохранения.
2. Распакуйте ZIP и поместите `.scs` в папку `mod` пользовательского каталога ETS2.
3. Активируйте **«Renault Master — проверка базы (без грузов)»**. Оба исходных пакета одновременно с ним должны быть отключены.
4. Проверьте покупку автомобиля, доступные кузова и салоны, двигатель, короткую поездку, сохранение и повторную загрузку.
5. После тестового запуска сохраните `game.log.txt`. Он нужен для проверки ошибок именно этой сборки.

Полная инструкция доступна по ссылке выше. Подробные отчёты проверки лежат отдельно от ZIP в [каталоге validation](validation/).

## Открытый технический вопрос

Требуется оплачиваемая доставка через Cargo Market, но груз должен находиться строго внутри фургона и пользователь исключил действия с прицепом. Для ETS2 1.61.1.1s подходящий механизм пока не подтверждён. Этот архив не выдаётся за решение данного требования; тест исходной машины и исследование грузовой механики являются разными этапами.
